# Вес — дневник веса с динамикой и скоростью изменений

Микросистема для ведения дневника веса: добавление записей, просмотр динамики,
расчёт изменения и скорости (г/день). Данные — в JSON, скрипты — на Python.
Проект простой: его легко изучить и переделать под свои нужды.

## Требования

- Linux (проверено на Ubuntu; должно работать на любом дистрибутиве с Bash и Python 3.9+)
- Python 3.9+ (проверить: `python3 --version`)
- Bash (обычно уже есть в Linux)

Проект не тестировался на Windows и macOS. Если вы на Windows — можно использовать
WSL (Windows Subsystem for Linux) или Git Bash, но это не гарантируется.

## Что внутри

```
weight/
├── scripts/
│   ├── add_weight.py          # добавить запись
│   ├── show_weight.py         # показать динамику
│   ├── remove_weight.py       # удалить запись по дате
│   ├── migrate_weight.py      # миграция структуры (если понадобится изменить формат)
│   └── Прибамбасы.py          # библиотека функций (в процессе создания)
├── weight.example.json        # ПРИМЕР данных (обезличенный)
├── weight.sh                  # обёртка/диспетчер (алиас `wes`)
├── README.md                  # этот файл
├── LICENSE                    # MIT
└── .gitignore                 # чего здесь нет из локальной папки проекта weight
```

Важно: файла `weight.json` в репозитории нет — он в `.gitignore`,
потому что это личные данные. Чтобы начать, создайте
копию `weight.example.json` с именем `weight.json`:

```bash
cp weight.example.json weight.json
```

После этого `weight.json` — Ваш файл с Вашими данными, отредактируйте его
Вашим любимым текстовым редактором.
`weight.example.json` — не трогайте, он остаётся примером.

## Установка и запуск

1. Скачайте папку с проектом на свой компьютер

### Способ 1: через Git (рекомендуется)

Склонируйте репозиторий:

```bash
git clone https://github.com/EvgenMironov900/weight.git
cd weight
```
`git clone` — скачивает все файлы проекта с GitHub в папку `weight` в текущей директории.
`cd weight` — переходит в эту папку.

### Способ 2: без Git (скачать архив)

Если у вас не установлен Git — можно скачать архив с релизом:

Откройте страницу релизов: [https://github.com/EvgenMironov900/weight/releases](https://github.com/EvgenMironov900/weight/releases)

Скачайте Source code (zip) (для Windows) или Source code (tar.gz) (для Linux/macOS).
Распакуйте архив — получите папку с файлами проекта.

Оба способа дают одинаковый результат: папку weight с файлами проекта.

2. Скопируйте пример данных (об этом уже написано в пункте "Что внутри"):

```bash
cp weight.example.json weight.json
```

3. Добавьте алиас `wes` в `~/.bashrc` (замените путь на свой):

```bash
echo "alias wes='/полный/путь/к/weight/weight.sh'" >> ~/.bashrc
source ~/.bashrc
```

4. Проверьте:

```bash
wes
```

## Как пользоваться

- Показать динамику: `wes` (или `python3 scripts/show_weight.py`)
- Добавить вес: `wes 86.5` (или `python3 scripts/add_weight.py 86.5`)
- Добавить вес с комментарием: `wes 86.5 "после прогулки"`
- Удалить запись по дате: `python3 scripts/remove_weight.py 2026-11-10`
- Миграция структуры (если понадобится): `python3 scripts/migrate_weight.py`

## Формат данных

`weight.json` — это JSON с «шапкой» (метаданные) и массивом записей:

```json
{
  "weight_journal": {
    "version": "1.0",
    "created": "2026-01-01",
    "updated": "2026-01-03",
    "author": "Ваше имя",
    "entries": [
      { "date": "2026-01-01", "weight": 80.0, "note": "начало" },
      { "date": "2026-01-02", "weight": 79.8, "note": "" },
      { "date": "2026-01-03", "weight": 79.6, "note": "" }
    ]
  }
}
```

## Принцип работы с JSON

- Загружать существующий JSON (не перезаписывать структуру).
- Добавлять только новые данные.
- Обновлять метаданные (`updated`).
- Сохранять с переводом строки.

## Шаблон для любого проекта

Скрипты можно адаптировать под любые данные:

- Скрипт добавления (`add_weight.py`) — адаптируйте под свои поля.
- Скрипт просмотра (`show_weight.py`) — адаптируйте под свои данные.
- Скрипт миграции (`migrate_weight.py`) — если меняете структуру.
- Скрипт удаления (`remove_weight.py`) — если нужно «подчистить» данные.
